    Can you continue?

    The next phase needs this one verbatim, or there's room left in the ~150k smart zone. Continue.

  2. 2

    Is this context irrelevant to what's next?

    Everything here is disposable. /clear. Clearing relevant context loses the why for good.

  3. 3

    Is something travelling?

    New harness, new directory, a colleague, or a side task forked mid-phase. /handoff.

  4. 4

    Can it run AFK?

    Tightly scoped, no steering needed, like an automated review. Send it to a subagent.

    Otherwise

    Relevant context, same place, you stay in the loop. /compact with an instruction for what to keep.
